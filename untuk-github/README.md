# Papan Pergerakan Staf JTMK

Papan digital yang menggantikan papan putih di Jabatan Teknologi Maklumat & Komunikasi (JTMK), Politeknik Balik Pulau:
siapa **ada** di pejabat, siapa **HBH**, dan siapa **tiada** (kursus, bengkel, mesyuarat luar, cuti…).

- Log masuk dengan **emel sahaja** (tiada kata laluan); admin boleh hidupkan emel + kod.
- Isnin, Rabu, Jumaat di pejabat; Selasa, Khamis HBH (kecuali staf yang sentiasa di pejabat).
- Data dibaca dan ditulis ke Google Sheet **PERGERAKAN STAFF** (tab bulanan) melalui Google Apps Script.
- Boleh dipasang di telefon (PWA) dan di-embed dalam Google Sites (butang **Buka penuh** muncul dalam bingkai).
- **Import cuti dari Excel** (laporan HR *ReportCutiDanStatus*): admin & Ketua Jabatan; pratonton dahulu, tiada rekod berganda, No. K/P tidak dibaca.
- **Dashboard** (halaman utama): rumusan Hari ini / Minggu ini / Bulan ini — siapa tiada, purata, sebab tiada, carta & akan datang.
- **Admin: Tambah pergerakan staf** — satu borang untuk seorang atau ramai staf, dengan tarikh pantas.
- **Mod Kalendar**: paparan sebulan; tekan satu hari untuk butiran dalam tetingkap.
- Komputer: menu sisi kiri. Telefon: nav bawah.
